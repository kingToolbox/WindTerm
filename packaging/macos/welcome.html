WindTerm SDK

This installer places the open source WindTerm libraries and their headers under /usr/local/windterm.

This is not the WindTerm application. WindTerm is a partial open source project: the terminal, the user interface and the session handling are not published, so they cannot be built from this repository. What you get here is the reusable part: the regex engine (Onigmo), libssh, the pseudo terminal backend, the Telnet protocol, and a few Qt widgets.

The libraries are built natively for the architecture named in the package file name.
